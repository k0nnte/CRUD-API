to start

go to the branch 
"develop" 
git-checkout "develop" 

install dependencies 
npm install 
run the required script (in the package.json file) 
for example: npm run start:dev

{ 
"username": "anna", 
"age": 20, 
"hobbies": ['string'] 
},
